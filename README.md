## Editar o conteúdo

Acesse /admin.html no site e use o botão do Pages CMS. Entre com GitHub, autorize o Pages CMS no repositório e edite os campos em Conteúdo do site. As alterações salvas no GitHub são publicadas pelo GitHub Pages.

O arquivo .pages.yml define os campos editáveis e content.json guarda os textos e contatos. Não salve senhas nem tokens nos arquivos públicos.
