O site foi preparado para você alterar textos, serviços, telefone, WhatsApp e informações de atendimento pelo Pages CMS. As edições são salvas no seu repositório GitHub e o GitHub Pages atualiza o site.

  1. Toque em Abrir painel de edição e entre com sua conta GitHub.
  2. Instale/autorize o Pages CMS para acessar o repositório que contém este site.
  3. Abra Conteúdo do site, altere os campos desejados e salve.
Primeiro acesso: o arquivo .pages.yml já prepara os campos editáveis. O Pages CMS precisa ser autorizado na sua conta GitHub e instalado no repositório uma vez. Não coloque senha nem token do GitHub dentro do site.
